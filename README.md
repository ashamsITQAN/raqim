# رقيم (RAQIM)

**Recitation Audio Quran Integrated Manager** — أداة مجانية في ملف واحد لتجهيز المصاحف الصوتية وفق معيار **مرقوم** (الدليل الإلزامي القرآني الكلّي الموحد) من [إتقان](https://itqan.dev).

تأخذ الأداة مصحفًا صوتيًا من 114 ملفًا وتخرجه جاهزًا للرفع على فنار وغيره من الأنظمة:

- **التسمية الخارجية:** أسماء ملفات مطابقة لمعيار مرقوم (البند 12.4)، مثل `QR_SC1447_Ibrahim-Addosari_As-Hf_mdd_BR128_FX_001.mp3`.
- **البيانات الداخلية:** العنوان والقارئ والألبوم والناشر ورقم السورة وصورة الغلاف (البند 12.5)، بترميز UTF-16 مع BOM في MP3، وUTF-8 وفق معيار MP4 في M4A.
- **التحويل:** إلى MP3 بمرمِّز LAME 3.100 الأصلي، أو إلى M4A (AAC) بمرمِّز Fraunhofer FDK AAC، بالجودات 64 و128 و256 و320.
- **الفحص:** التحقق من مطابقة أسماء مصحف موجود للمعيار حقلًا حقلًا.

## الاستعمال

1. نزّل الملف [`raqim.html`](raqim.html) وافتحه في Chrome أو Edge على الحاسوب. لا يحتاج إلى تثبيت ولا إنترنت.
2. اختر حالة مصحفك من صفحة البداية، واتبع الخطوات.

كل المعالجة تجري داخل المتصفح، والملفات لا تغادر الجهاز.

### نسخة سطح المكتب (ويندوز)

نزّل `Raqim-<الإصدار>-windows-x64.zip` من صفحة [Releases](../../releases)، وفك ضغطه، وشغّل `Raqim.exe`. لا يحتاج إلى تثبيت.

- الواجهة نفسها في نافذة برنامج مستقلة (عبر Edge)، والتحويل بالمرمِّزين نفسيهما مبنيَّين أصليًا لويندوز، مع نسخة AVX2 تُختار تلقائيًا إن دعمها المعالج.
- الملفات الناتجة **متطابقة بايتًا ببايت** مع نسخة المتصفح، وتحويل MP3 بأعلى دقة أسرع بنحو 1.7 مرة.
- البرنامج غير موقّع رقميًا، فقد يظهر تحذير ويندوز أول مرة: More info ← Run anyway.

## إعادة بناء المرمِّزين

```sh
pip install ziglang
sh encoders/build.sh            # يبني encoders/dist/lame.wasm و aac.wasm
python3 encoders/embed.py raqim.html   # يدمجهما في الأداة
```

سكربت البناء يجلب مصادر LAME وFDK AAC من مستودعاتها الأصلية عند الإصدارات نفسها التي استُعملت في رقيم.

ولبناء نسخة سطح المكتب بعده:

```sh
sh native/build_windows.sh      # يبني native/dist/Raqim.exe
```
